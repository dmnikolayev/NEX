# NEX Living House v0.2

## Запуск

```bash
cd NEX-LivingHouse-v0.2
python3 -m http.server 8080
```

Відкрити `http://localhost:8080`.

## Зафіксована концепція

- Будинок — головний герой.
- Чотири маленькі дисплеї: трансформатор, панелі, Deye, акумулятор.
- Starlink біля антени.
- Погода праворуч угорі.
- Стан будинку текстом на хмарах.
- Без назв пристроїв на дисплеях.
- Дані не дублюються.
- Координати у `layout/*.json`.
- Дані у `js/house-state.js`.

Фон поки замінний незалежно від коду.
